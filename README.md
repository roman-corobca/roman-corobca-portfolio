# Roman COROBCA — Portfolio BTS SIO SISR

Portfolio statique : accueil, épreuves, ateliers professionnels, veille, certifications et contact.

## Publication

Configurer GitHub Pages avec la source GitHub Actions. Chaque modification poussée sur main publie les fichiers du dossier site/. Le workflow utilise les actions officielles GitHub.

## Maintenance

Modifier site/collections.json pour les contenus. Le site contient également des données de repli dans site/app.js : maintenir leur cohérence. Les liens sont relatifs pour fonctionner sous le chemin du dépôt GitHub Pages.

Le formulaire de contact reste désactivé tant qu’aucune adresse destinataire n’est configurée. GitHub Pages ne fournit pas de serveur d’envoi. Les sujets Odoo restent des propositions. La veille du mardi doit pousser ses modifications dans ce dépôt pour qu’elles deviennent publiques ; la connexion au dépôt n’est pas encore configurée.
